## Run Locally

```bash
git clone https://github.com/ajikarar-jpg/ai-engineer-portfolio.git
cd ai-engineer-portfolio
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

```bash
npm run lint
npm run build
```

Set `NEXT_PUBLIC_SITE_URL` to the live origin when you want social metadata to use absolute URLs.
